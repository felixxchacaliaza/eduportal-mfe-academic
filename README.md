# 🏛️ MFE Gestión Académica • EduPortal Microfrontend Remoto

> **Dominio:** eduportal-mfe-academic  
> **Puerto Local:** `4203`  
> **Tecnología:** Angular 22 Zoneless + Native Federation (`@angular-architects/native-federation`)  
> **Exportación:** `./routes` vía `remoteEntry.json`  
> **Repositorio:** [https://github.com/felixxchacaliaza/eduportal-mfe-academic](https://github.com/felixxchacaliaza/eduportal-mfe-academic)  

### 🚀 Arranque Autónomo
```bash
npm install --legacy-peer-deps
npm start
```
Navega a `http://localhost:4203` para acceder al microfrontend en modo aislado.
